# 💼 Personal Business Card

A simple and clean personal business card website created using **HTML5 and CSS3**.

## 📌 About the Project

This project is a digital business card that displays personal information such as name, profession, and location.

## ✨ Features

* 👤 Profile image
* 💼 Frontend Developer profile
* 📍 Location information
* 🎨 Simple and clean card design
* 💻 Built with HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Business-Card/
│
├── Businness_card.html
├── card.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `Businness_card.html`.
4. Run the HTML file in your browser.
